
# Travelore

## Introduction
"Travelore" is a sleek tour and travel booking site built with Node.js and Express.js, using MongoDB for data storage. It delivers a seamless, personalized experience for vacation planning and booking, featuring secure user authentication for account creation and management.

## Technology Stack
- HBS (Handlebars): It is a templating engine which generate dynamic HTML content by embedding JavaScript expressions into HTML files
- Bootstrap: A popular front-end framework for designing responsive and mobile-first websites using pre-built CSS and JavaScript components.
- Node.js: A JavaScript runtime for building server-side applications.
- MongoDB: A NoSQL database for storing and managing event data.
- Express.js: A web application framework for Node.js, used for building RESTful APIs.

## Features
- Booking Available Plans: Users can browse and book Travel Plans available on the platform.
- Requesting Own Plan: Users can create their own Travel Plan and request for a callback.
- Responsive layout: The website is optimized for various devices, ensuring a seamless user experience.
- Newsletter - User Can subscribe newsletter to get aware of upcoming Offers and news
- Contact Us - User can Fill Contact Us Form to request a callback
- Admin Dashboard - Admin can view Bookings, Contacts, Users, Newsletter subscribers
